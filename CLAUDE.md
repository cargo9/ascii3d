## Что это
Команда `ab <файл>` (функция в ~/.bashrc): тихо пересобирает проект и запускает `build/ascii3d`.
- Картинки: stb_image (jpg/png/bmp/gif/tga/psd/hdr/pnm), nanosvg (svg),
  остальное (webp/heic/avif) — через `magick` в PNG. Вывод — ASCII с truecolor, `-b` — полублоки ▀.
- 3D: .obj (+ цвета Kd из .mtl) и .stl (бинарный/текстовый; Z-up → Y-up).
  Свой софтверный растеризатор: z-буфер (1/z), гладкие нормали с порогом 40°, Ламберт + блик.
  Интерактив: alt-экран, termios raw, мышь (SGR 1006). Поворот — матрица orient, докручивается
  относительно экрана; автокувырок по 2 осям (у симметричных моделей вращение вокруг одной оси не видно!).
  Колесо — зум модели, Ctrl+колесо — размер шрифта. `--once` — один кадр.
- Картинки в tty открываются полноэкранно (imageview.cpp), перерисовка при смене размера; `-p` — просто печать.
- Ctrl+колесо = `alacritty msg config font.size=…` (fontzoom.cpp), при выходе `alacritty msg config -r`.
  В тестах запускать с `env -u ALACRITTY_WINDOW_ID`, чтобы не менять шрифт пользователю.
- Без файла — демо-пончик (`--cube` — куб).

## Структура
- `src/main.cpp` — разбор аргументов, выбор по расширению
- `src/term.*` — терминал (размер, raw-режим, восстановление по Ctrl+C/atexit)
- `src/image.*` — загрузка и ASCII-рендер картинок
- `src/mesh.*` — загрузка OBJ/STL, демо-модели, нормализация и нормали
- `src/viewer3d.*` — 3D-рендер и интерактивный цикл
- `src/imageview.cpp` — полноэкранный просмотр картинки
- `src/fontzoom.*` — размер шрифта Alacritty через IPC
- `src/vec.h` — Vec3/Mat3
- `third_party/` — stb_image.h, nanosvg.h, nanosvgrast.h (подключены как SYSTEM)
- `examples/` — тестовые файлы

## Сборка и проверка
```
ab examples/rocket.obj            # интерактивно
build/ascii3d file --once --mono -w 60 -H 20   # кадр текстом — удобно для проверки
```
Сборка должна быть без warning-ов (-Wall -Wextra -Wpedantic).
